Lab Objective:

Learn how to install and configure a multilayer switch.

Lab Purpose:

Many vendors supply basic (layer 2) switches, as well as higher-specification switches that can perform routing (layer 3) or content switching (layers 4–7). The main difference between how switches route traffic and how routers do is that switches use application-specific integrated circuits (ASICs), whereas routers use software/CPU.
