Lab Objective:

The objective of this lab is to learn how to filter MAC addresses on a wireless router.

Lab Purpose:

MAC filtering is a security method based on access control. Every device has a 48-bit hardware address which MAC filtering uses to determine whether it can access a network or not.

My Thoughts:
In this lab we connected two laptops to a wireless router.
In our router setting we went to our Mac Filtering settings.
Using ipconfig /all on our laptops we determined our MAC addresses.
We went back to our router settings and input them into our routers MAC filter.
Our options includeed restricting access per MAC address or allowing access per MAC address.
For the lab, we restricted access from one laptop, confirming it via the NIC settings that it could not connect to the router.
